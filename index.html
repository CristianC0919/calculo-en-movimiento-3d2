¿Cómo funciona?

HTML crea la interfaz. CSS organiza el diseño. JavaScript coordina cámara, gestos y resultados. Math.js interpreta funciones y derivadas. Three.js dibuja la gráfica. MediaPipe Hands detecta la mano.

1 dedo  → f(a) y pendiente
2 dedos → secante y cociente incremental
3 dedos → f(x), f′(x), f″(x)
4 dedos → críticos, máximos y mínimos
5 dedos → razón de cambio

Manual rápido

  1. Abre la app mediante HTTPS/GitHub Pages.
  2. Escribe una función y pulsa Aplicar.
  3. Activa la cámara y acepta el permiso.
  4. Usa 1–5 dedos para las interacciones.
  5. Si falla la cámara, usa 1–5 con teclado, ← → para mover a y [ ] para cambiar h.
