# Cálculo en Movimiento — entrega final

Aplicación web estática para el proyecto de Cálculo Diferencial. Incluye cámara con MediaPipe Hands, cinco gestos, Math.js para derivadas y Three.js para la gráfica.

## Archivos
- `index.html`: estructura de la aplicación.
- `style.css`: interfaz.
- `app.js`: cámara, reconocimiento, matemática y gráfica.

## Uso
Sube los tres archivos a GitHub Pages. Abre la página, escribe una función, pulsa Aplicar y activa la cámara. Para probar sin cámara: teclas 1–5, flechas y `[ ]`.

La cámara requiere HTTPS.

## Interacciones
1 dedo: evaluación y pendiente.
2 dedos: secante y cociente incremental.
3 dedos: f, f' y f''.
4 dedos: máximos, mínimos y puntos críticos.
5 dedos: reto de razón de cambio.
