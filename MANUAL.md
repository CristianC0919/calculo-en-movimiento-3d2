# Manual de usuario

1. Abra la aplicación en GitHub Pages.
2. Escriba una función como `x^3 - 3*x` y pulse Aplicar.
3. Active la cámara y acepte el permiso.
4. Levante de 1 a 5 dedos.
5. Use flechas para mover `a` y `[ ]` para cambiar `h`.
6. Si la función es inválida, aparecerá un mensaje y se conservará la función anterior.
7. Antes de entregar, pruebe las cinco interacciones y verifique los resultados matemáticos.
